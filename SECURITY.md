# Security Policy

## Reporting

Do not open a public issue for vulnerabilities that could enable arbitrary command execution, bypass the device guard, leak private device information, or flash unverified images.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/logix727/MetroidRescue/security/advisories/new

Do not attach phone serial numbers, credentials, firmware containing personal data, or unredacted support bundles.

## Supported versions

Only the latest GitHub release is supported. This project is experimental and carries no warranty; see `LICENSE` and `MetroidRescue.Avalonia/RELEASE_BLOCKERS.md`.
